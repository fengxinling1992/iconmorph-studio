# IconMorph Studio

> 以 SVG 轮廓为真源的在线 AI 图标风格化工作台。

IconMorph Studio 面向设计师、前端开发者和产品团队，提供从 SVG 图标到多种视觉变体的实时生成、对比和导出能力。工具坚持使用源 SVG 轮廓作为资产真源，不需要先导出位图或垫图，即可调整颜色、渐变、玻璃质感、挤出厚度和 3D 场景套件，并将结果下载为可编辑 SVG 或透明底 PNG。

## 主要能力

### SVG 图标库与导入

工具内置项目图标字体库，按业务分组展示图标，并支持分组 Tab、名称或编码搜索。你也可以导入自己的 SVG 图标；导入图标会在统一尺寸的卡片中预览，并保留源 SVG 结构用于后续渲染。

### 五类风格模板

| 风格 | 能力说明 |
|---|---|
| 双色分层 | 使用主色与辅助色形成双色结构，支持挤出面配色、投影参数和独立镂空颜色。 |
| 线性渐变 | 将渐变应用于整个 SVG 整体形状，支持起止颜色与渐变角度。 |
| 柔和玻璃 | 提供独立的微软式磨砂玻璃参数，包括冷光配色、透光强度、扩散浓度和边缘反射。 |
| 2.5D 轻拟物 | 支持整体正面渐变、挤出厚度、挤出角度、双分面配色和复杂轮廓安全模式。 |
| 3D 插画场景 | 将 SVG 主体放入独立的等轴测场景，支持斜切、外轮廓挤出、白色镂空、底座、点缀装饰和围绕装饰。 |

所有应用渐变的风格均以整个 SVG 形状作为渐变对象，而不是对图标区域进行不一致的分块渐变。双色、2.5D 与 3D 场景中的内部闭合镂空会独立渲染，默认使用白色填充，并可在对应面板中单独调整。

### 3D 插画场景

3D 场景拥有独立于其他风格的参数体系，不会复用 2.5D 的厚度和角度设置。当前场景能力包括：

- 3D 挤出厚度支持最高 **200 px**，默认厚度为 **92 px**，默认挤出角度为 **325°**。
- 3D 主体支持 20°、30°、40° 斜切强度预设。
- 新增 **图标尺寸**控制，范围为 50%–150%，默认 100%，以 SVG 规范画布中心点为中心同步缩放主体、挤出面、镂空和高光。
- 底座支持“无 / 底座1 / 底座2”，底座2使用仓库内置 SVG 素材。
- 点缀装饰支持“无 / 玻璃球 / 方块 / 自定义上传”。
- 围绕装饰支持“无 / 飘带 / 环绕 / 自定义上传”。
- 点缀装饰和围绕装饰分别提供独立高度调节。
- 复杂轮廓安全模式会自动收窄极细路径的有效挤出厚度，降低尖刺和异常面风险。

## 使用流程

1. 在左侧图标库中搜索并选择一个图标，或通过“导入 SVG”上传自己的图标。
2. 在风格模板区域选择双色、渐变、玻璃、2.5D 或 3D 插画场景。
3. 在右侧参数面板调整当前风格专属参数。面板只显示当前风格相关控件，避免不同风格之间的参数混淆。
4. 在中间预览区域查看多个变体，并使用对比模式检查源 SVG 与变体效果。
5. 在导出面板中选择 SVG 或透明底 PNG。PNG 支持 2x、3x、4x 分辨率；也可以将选中的结果打包为 ZIP 直接下载。

## 导出说明

SVG 导出保留矢量结构，适合继续编辑和二次设计。对于 3D 插画、复杂毛玻璃模糊和部分光影效果，SVG 的跨软件表现可能存在差异；如果需要完整保留所见的质感，建议同时导出透明底 PNG。

批量导出使用浏览器下载器直接保存到本地，不依赖服务端文件存储。导出的 SVG 会包含当前预览所需的图层、渐变、滤镜和场景素材引用。

## 本地开发

### 环境要求

- Node.js 22 或更高版本
- pnpm 10 或更高版本

### 安装与启动

```bash
pnpm install
pnpm dev
```

默认开发地址为 <http://localhost:3000/>。生产构建、类型检查和测试命令如下：

```bash
pnpm build
pnpm check
pnpm test
```

## 项目结构

```text
client/
  public/manus-storage/       # GitHub Pages 使用的内置图标库和场景素材
  src/pages/Home.tsx          # 主工作台与参数面板
  src/lib/iconRenderer.ts     # SVG、2.5D 和 3D 场景渲染器
  src/App.tsx                 # 应用入口
.github/workflows/
  deploy-pages.yml             # GitHub Pages 自动部署工作流
server/                        # 本地开发环境兼容代码
shared/                        # 共享类型与常量
todo.md                        # 功能与验证记录
```

## GitHub Pages 部署

项目使用 `pages` 分支触发 GitHub Actions。工作流会安装依赖、执行 Vite 构建、上传 `dist/public` 静态产物，并通过 GitHub Pages 发布。图标库和 3D 场景套件已内置在仓库的 `client/public/manus-storage/` 中，线上版本不依赖 Manus 外部存储路径。

如需在自己的仓库中部署，请将仓库 Pages 设置为 **GitHub Actions**，并确保工作流所在分支与触发分支一致。Vite 使用 `import.meta.env.BASE_URL` 处理项目子路径，因此适用于 `username.github.io/repository-name/` 形式的项目站点。

## 设计原则

IconMorph Studio 将 SVG 轮廓视为唯一的几何来源。颜色、渐变、挤出、镂空和场景装饰都是围绕源轮廓生成的可控变体，而不是预先制作的静态图片。这样可以让同一枚图标在不同风格模板之间保持形状一致，并支持实时调整与批量输出。
